# Campo Alegre

Campo Alegre es un proyecto sencillo de tienda en línea inspirada en un supermercado, creado con HTML, CSS y JavaScript. La idea principal es mostrar una interfaz visual atractiva donde el usuario puede navegar por distintas categorías de productos, ver ofertas destacadas y simular una experiencia básica de compra.

## ¿Qué hace este proyecto?

El sitio está pensado como una página de e-commerce pequeña y funcional. Permite:

- visualizar una página principal con productos y categorías
- acceder a páginas de detalle de productos destacados
- agregar y quitar artículos de forma simple desde la interfaz
- ver un contador de carrito en la parte superior
- aplicar un descuento a una promoción especial
- explorar una estructura de navegación clara y ordenada

## Estructura del proyecto

La carpeta está organizada de forma muy simple para que sea fácil de entender:

- inicio.html: página principal del supermercado
- producto1.html: detalle del producto de té matcha
- producto2.html: detalle del combo navideño
- inicop.css: estilos generales del sitio
- valoracion.css: estilos para la sección de valoraciones
- producto1.js, producto2.js, promocion2.js, stock.js: lógica interactiva del carrito, stock y promociones
- img/: imágenes de productos, banners y recursos visuales
- icono/: iconos usados en la interfaz

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript vanilla

## Cómo ver el proyecto

Solo necesitas abrir el archivo inicio.html en tu navegador para explorar la página.

## Nota

Este proyecto funciona como una práctica de maquetación y programación básica en JavaScript, con un enfoque muy visual y didáctico. Es un ejemplo claro de cómo construir una interfaz de tienda sencilla paso a paso.
